# FocusTracker

**FocusTracker** is a simple iOS-focused task/focus tracker app built in Swift. It helps you stay focused by letting you set a timer for a task session (focus time) and a break session, and logs completed tasks with their duration and date.

---

## 📌 Features

- 🕒 **Focus Timer:** Name a task and set your focus duration (in minutes).  
- ☕ **Break Timer:** Define a break period to rest after focus time.  
- 📊 **Task History:** View completed tasks with timestamps and duration.  
- ✅ **Simple UI:** Lightweight and intuitive interface for quick task tracking.
